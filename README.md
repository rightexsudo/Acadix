## ما هي الأداة؟

تكتب مجالاً مثل «تحليل البيانات» أو «Python»، وتختار مستواك، فتحصل خلال ثوانٍ على:

1. **ملخص** عن أهمية المجال لمستواك.
2. **أربع مراحل** (تأسيس، توسع، احتراف، سوق العمل)، لكل مرحلة 3 إلى 5 مهام قابلة للتنفيذ.
3. **منارات للتعلّم:** روابط دورات وفيديوهات مرتبطة بالموضوع.

ثم تتابع تقدمك بتحديد المهام المنجزة، فتضيء نجوم السماء تدريجياً.

## كيف تستخدمها؟

1. **اكتب الموضوع** في مربع البحث، أو اضغط أحد الوسوم الجاهزة (Python، تطوير الويب، الذكاء الاصطناعي...).
2. **اختر المستوى:** مبتدئ، متوسط، أو متقدم.
3. اضغط **توليد**، وانتظر بضع ثوانٍ أثناء ظهور شاشة التحميل.
4. **حدّد المهام** التي أنجزتها: تُضيء النجمة وتتصل بالخط الذهبي، وتتحرك حلقة النسبة المئوية. وعند إكمال مرحلة كاملة يتوهج إطارها.
5. **احفظ أو شارك:**
   - زر **📷 حفظ كصورة** يصدّر الخارطة PNG.
   - زر **🔗 نسخ رابط المشاركة** يعطي رابطاً دائماً (متاح عند تفعيل قاعدة البيانات).
6. من قسم **مكتبتي** ترجع لأي خارطة سبق أن ولّدتها، وهي تُحفظ تلقائياً في متصفحك.

> تقدمك ومكتبتك محفوظان في متصفحك فقط (`localStorage`)، فمسح بيانات المتصفح يمحوهما.

## التشغيل محلياً خطوة بخطوة

### ما تحتاجه

- **Python 3.10 أو أحدث** ([تحميل](https://www.python.org/downloads/))، وعلى ويندوز فعّل خيار *Add Python to PATH* أثناء التثبيت.
- **Git** ([تحميل](https://git-scm.com/downloads)) أو حمّل المشروع كملف ZIP من GitHub.
- **مفتاح Groq مجاني** من [console.groq.com/keys](https://console.groq.com/keys).

### الخطوات

**1. حمّل المشروع**

```bash
git clone https://github.com/rightexsudo/Acadix.git
cd Acadix
```

**2. أنشئ بيئة افتراضية** (يُنصح بها حتى لا تتعارض المكتبات)

ويندوز:
```powershell
python -m venv venv
venv\Scripts\activate
```

لينكس وماك:
```bash
python3 -m venv venv
source venv/bin/activate
```

**3. ثبّت المكتبات**

```bash
pip install -r requirements.txt
```

**4. ضع مفتاح Groq في متغير بيئة**

ويندوز PowerShell:
```powershell
$env:GROQ_API_KEY="ضع_مفتاحك_هنا"
```

ويندوز CMD:
```bat
set GROQ_API_KEY=ضع_مفتاحك_هنا
```

لينكس وماك:
```bash
export GROQ_API_KEY="ضع_مفتاحك_هنا"
```

> المتغير يعيش في نافذة الطرفية الحالية فقط. إن أغلقتها فأعد الأمر. ولا تكتب المفتاح داخل `app.py` ولا ترفعه إلى GitHub.

**5. شغّل الأداة**

```bash
python app.py
```

**6. افتح المتصفح** على العنوان الذي يظهر في الطرفية (غالباً `http://127.0.0.1:5000`).

لإيقاف الخادم اضغط `Ctrl + C`.

## الإعدادات الاختيارية

الأداة تعمل بمفتاح Groq وحده. هذه المتغيرات تضيف ميزات:

| المتغير | الوظيفة |
|---|---|
| `GROQ_API_KEY` | **مطلوب.** مفتاح Groq |
| `DATABASE_URL` | رابط قاعدة Postgres (مثل [Neon](https://neon.tech) المجانية). يفعّل الكاش الدائم وروابط المشاركة والإحصاءات |
| `ADMIN_TOKEN` | رمز سري تفتح به صفحة الإحصاءات `/stats?token=...` |

لتوليد رمز قوي:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

عند ضبط `DATABASE_URL` يُنشأ جدول `roadmaps` تلقائياً عند أول تشغيل. وبدونه تعمل الأداة كاملة عدا المشاركة والكاش الدائم.

## توليد خرائط جاهزة

للمواضيع الشائعة يمكنك توليد الخرائط مرة واحدة وحفظها في `popular.json`، فتُخدَم فوراً بلا استهلاك من حصة Groq:

```powershell
$env:GROQ_API_KEY="ضع_مفتاحك_هنا"
python make_popular.py
```

- يولّد 33 خريطة (11 موضوعاً × 3 مستويات) ويستغرق نحو 15 دقيقة لاحترام حدود Groq.
- آمن لإعادة التشغيل: يتخطى ما تم توليده، ويحفظ بعد كل خريطة.
- يجب أن يكون `popular.json` بجانب `app.py`.

## النشر على الإنترنت

الأداة جاهزة للنشر على [Render](https://render.com):

1. ارفع المشروع إلى مستودع GitHub.
2. أنشئ **Web Service** وارنبطه بالمستودع.
3. **Build Command:** `pip install -r requirements.txt`
4. **Start Command:** `gunicorn app:app --workers 1 --threads 8 --timeout 60`
5. أضف المتغيرات من قسم **Environment** (وليس من الكود).
6. اختياري: اجعل خدمة مراقبة مجانية (مثل UptimeRobot) تزور `/health` كل 10 دقائق، حتى لا تنام الخدمة المجانية.

> الطبقة المجانية على Render تنام بعد 15 دقيقة بلا زيارات، وحصة Groq المجانية هي ما يحدّ عدد الخرائط اليومية. الكاش والسلسلة الاحتياطية للموديلات يخففان ذلك.

## الميزات

**للمستخدم**
- خارطة مخصصة لأي موضوع ومستوى، بأربع مراحل ومهام واضحة.
- سماء تفاعلية: نجوم تُضاء، وخطوط تُرسم، وحلقة تقدّم، وأسماء نجوم عربية للكوكبات.
- مكتبة محلية تحفظ خرائطك وتقدمك.
- حفظ كصورة، وروابط مشاركة دائمة.
- واجهة عربية RTL متجاوبة (حاسوب وجوال)، تدعم لوحة المفاتيح وتفضيل تقليل الحركة.

**للمطوّر**
- **مخرجات منظمة:** يطلب الخادم JSON من الموديل ويتحقق منه، وأي رد معطوب يُرفض.
- **سلسلة موديلات احتياطية** على Groq: `gpt-oss-120b` ← `gpt-oss-20b` ← `llama-3.3-70b` ← `llama-3.1-8b`. عند نفاد حصة موديل ينتقل الكود للتالي تلقائياً.
- **ثلاث طبقات كاش:** `popular.json`، ثم ذاكرة الخادم، ثم Postgres.
- **حد طلبات:** 6 خرائط جديدة في الساعة لكل IP (المخزنة لا تُحتسب).
- **الأمان:** لا يُحقن HTML من الذكاء الاصطناعي، والروابط الخارجية تُتحقق، والمدخلات محددة الطول.

| المسار | الوظيفة |
|---|---|
| `/` | الصفحة الرئيسية وتوليد الخارطة |
| `/r/<id>` | عرض خريطة مشاركة |
| `/health` | فحص الحالة |
| `/stats?token=...` | أكثر المواضيع طلباً (يتطلب `ADMIN_TOKEN`) |

## كيف تعمل من الداخل؟

```
المتصفح ──POST──► Flask ──► كاش؟ ──نعم──► الخارطة
                     │          │
                     │         لا
                     │          ▼
                     │     سلسلة موديلات Groq ──► JSON ──► تحقق ──► Markdown
                     │          │
                     │          ▼
                     │     بحث يوتيوب عن الدورات
                     ▼
              الواجهة تحوّل النص إلى كوكبات (JavaScript آمن)
```

```
Acadix/
├── app.py              # الخادم + القالب + منطق الذكاء الاصطناعي والكاش
├── requirements.txt    # المكتبات
├── popular.json        # خرائط جاهزة (اختياري)
├── make_popular.py     # سكربت توليدها (يُشغَّل محلياً فقط)
└── README.md
```

**التقنيات:** Flask · gunicorn · Groq API · PostgreSQL · youtube-search-python · HTML/CSS/JavaScript بدون إطار عمل · html2canvas

## حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError` | شغّل `pip install -r requirements.txt` داخل البيئة الافتراضية المفعّلة |
| تظهر رسالة «تعذّر توليد الخارطة» | تأكد من ضبط `GROQ_API_KEY` في **نفس نافذة الطرفية** التي شغّلت منها الأداة، وراجع الرسائل المطبوعة فيها |
| «الخدمة مشغولة» | نفدت الحصة المجانية لكل الموديلات مؤقتاً؛ جرّب بعد دقائق |
| «وصلت إلى حد الخرائط الجديدة» | حد الطلبات لكل IP (6/ساعة). جرّب موضوعاً من الوسوم الجاهزة أو عد لاحقاً |
| خطأ `proxies` من مكتبة يوتيوب | لازم `httpx==0.27.2`، وهو مثبت في `requirements.txt` فأعد التثبيت |
| `ImportError` عند تشغيل `make_popular.py` | تأكد أن `app.py` في المجلد نفسه وأنه آخر نسخة من المستودع |
| `Address already in use` | منفذ 5000 مشغول؛ أغلق البرنامج الآخر أو أعد تشغيل الطرفية |
| الأمر لا يعمل على ويندوز | `export` للينكس فقط؛ استخدم `$env:` في PowerShell أو `set` في CMD |
| مشاركة لا تظهر | زر المشاركة يحتاج `DATABASE_URL`؛ راجع سجل الطرفية عن سطر يبدأ بـ `DB:` |
